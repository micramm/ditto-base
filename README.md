# Ditto Base

A Pokémon GO fan site: Pokédex and Shinydex, live events, raid and Rocket counters, GO tools, medal tracker and mini games.

Live at https://micramm.github.io/ditto-base/

Pokémon data and images come from PokéAPI, ScrapedDuck/LeekDuck, PvPoke and the Pokémon GO game master. Pokémon is © Nintendo, Game Freak and The Pokémon Company. This is an unofficial fan site.
